# Reel Studio — استوديو الريلز

تصوّر نفسك بالجوال. كلود يعدّل الريل.

قصّ الصمت · كابشن يتبع صوتك بخطّك وأسلوبك · لقطات B-roll من حسابك في Higgsfield · مشاهد متحرّكة (ختم، عدّاد،
قائمة، فقاعة تعليق، سبوت لايت…) · كرت هوك وكرت ختام · غلاف بوستر · فحص جودة. وصفحة **استوديو** داخلية تقرّر منها
كل شيء مرّة واحدة وأنت ترى المعاينة الحيّة، ثمّ يُطبَّق على كل ريل.

> 🤲 هذي الأداة هدية من حسين المتروك — ادعِ له بالخير.

## التثبيت في تطبيق Claude (الطريقة السهلة)

1. افتح تطبيق Claude ← تبويب **Code**.
2. اضغط **+** جنب خانة الكتابة ← **Plugins** ← **Browse plugins**.
3. **Add** (فوق يمين) ← **Add marketplace** ← **Add from a repository**.
4. الصق هذا الرابط واضغط **Sync**:

```
https://github.com/dndhan-coder/reel-studio
```
5. ثبّت **Reel Studio** من القائمة.
6. افتح محادثة جديدة واكتب:

```
/reel setup
```

ثمّ:

```
/reel studio
```

تفتح لك صفحة الاستوديو في المتصفّح: اختر نوع الريل، والخطّ (١٢٣ خطّاً مجانياً)، وأسلوب الكابشن، ولونك وحسابك،
وB-roll، واللمسات — والمعاينة تتحرّك مع كل اختيار. اضغط **احفظ الإعدادات**.

بعدها، كل ريل: ارمِ ملفّ الفيديو في المحادثة أو اكتب مساره وقُل:

```
عدّل هالريل
```

## من الطرفية بدلاً من التطبيق

```bash
claude plugin marketplace add dndhan-coder/reel-studio
claude plugin install reel-studio@reel-studio
```

## من ملفّ مضغوط (بلا GitHub)

فكّ `reel-studio.zip` في مجلّد البيت (يصير `~/reel-studio`)، ثمّ في الطرفية:

```bash
claude plugin marketplace add ~/reel-studio
claude plugin install reel-studio@reel-studio
```

وفي تطبيق Claude: **Plugins ← Browse plugins ← Add ← Add marketplace ← Add from a local folder** واختر المجلّد.

## ما يحتاجه جهازك

| الأداة | لماذا | التثبيت |
|---|---|---|
| ffmpeg | القصّ والتركيب | ماك: `brew install ffmpeg` · ويندوز: `winget install ffmpeg` |
| Python 3.10+ | السكربتات | ماك فيه Python؛ ويندوز من python.org |
| whisper | التفريغ بتوقيت الكلمة | `/reel setup` يثبّته |
| Playwright + Chromium | رسم الكابشن والمشاهد | `/reel setup` يثبّته |
| Higgsfield CLI (اختياري) | لقطات B-roll **بحسابك أنت** | `curl -fsSL https://raw.githubusercontent.com/higgsfield-ai/cli/main/install.sh \| sh` ثمّ `higgsfield auth login` |

لا مفاتيح ولا حسابات داخل الأداة. كل ما تولّده من لقطات يُخصم من رصيد حسابك في Higgsfield، وكلود يسألك قبل كل دفعة.

## ما الذي يحدث لكل ريل

1. ينسخ الفيديو إلى `~/Movies/Reels/<اسم>/` ويقصّ الصمت ويطبّع الصوت.
2. يفرّغ كلامك بتوقيت كل كلمة، ويصحّح النصّ معك.
3. يعرض عليك خطّة: الكلمة الملوّنة في كل سطر، وأين تدخل لقطة، وأيّ مشهد — تقول «تمام».
4. يولّد اللقطات (إن شغّلتها)، ويرسم الكابشن والمشاهد، ويركّب كل شيء.
5. يبني الغلاف، ويفحص الناتج، ويفتح لك مجلّد `out/`: الريل، الترجمة srt، الغلاف، وورقة مصغّرات.

## تغيير الشكل لاحقاً

قُل «افتح الاستوديو» وغيّر ما تريد، أو قُل بالكلام: «خلّ الكابشن كاريوكي»، «غيّر الخطّ إلى Cairo»، «اللون أزرق».
ثمّ «ارسم من جديد» — اللقطات محفوظة ولا تُولَّد مرّة ثانية.

## خطّ خاصّ بك

عندك خطّ مرخّص؟ انسخ ملفّاته (ttf/otf) إلى `~/.reel-studio/fonts/custom/` واكتب اسمه في الاستوديو.

## التحديثات

في المحادثة: «حدّث الاستوديو». أو من الطرفية: `claude plugin marketplace update reel-studio` ثمّ
`claude plugin update reel-studio@reel-studio`. افتح محادثة جديدة بعد التحديث.
