# plan.json — صيغة الخطّة

الملفّ الذي يحوّل التفريغ إلى مونتاج. `reel.py plan` يكتب المسوّدة من `sentences.json` + الإعدادات، وأنت تحرّرها.
الأزمنة كلّها بثواني الـA-roll بعد القصّ (`work/aroll.mp4`).

```json
{
  "slug": "my-reel",
  "type": "talk",                       // talk | voiceover | tips | story  (من الإعدادات؛ تقدر تغيّره للريل هذا فقط)
  "language": "ar",
  "title": "٣ أخطاء المبتدئ",            // tips فقط: العنوان المثبّت فوق
  "hook": "خسرت ٥٠٠٠ دولار في يوم",      // story (أو أيّ نوع): كرت داكن قبل الصورة. فارغ = بلا كرت
  "hookSeconds": 2.2,
  "outro": {"text": "تابعني لمزيد", "seconds": 2.4},   // null = بلا ختام
  "zoomAnchor": 0.38,                   // موضع الوجه كنسبة من الارتفاع (0 فوق – 1 تحت)؛ الزوم يتمركز عليه
  "music": null, "musicGain": -20,      // مسار ملفّ موسيقى من عنده (اختياري) وقوّته بالديسيبل
  "coverAt": 0.8,                       // لحظة إطار الغلاف الافتراضيّ (cover.jpg من الريل نفسه)
  "cover": {                            // الغلاف البوستر (cover.png) — اختياري
    "pill": "الحلقة ٣", "tag": "DISCIPLINE", "at": 1.4, "bg": "work/aroll.mp4",
    "lines": [["حسابك صار", ""], ["صفر؟", "accent"]]      // [نصّ, لون]: "" أبيض · "accent" لونه · "#hex"
  },
  "scenes": [ ... ],                    // انظر «المشاهد» تحت
  "sentences": [
    {
      "id": "s01", "start": 0.0, "end": 1.9,
      "text": "اليوم بعلّمك ثلاث أخطاء",
      "words": [{"w": "اليوم", "s": 0.0, "e": 0.42}, {"w": "بعلّمك", "s": 0.45, "e": 0.9}, ...],
      "em": [2],                        // فهارس الكلمات المهمّة (من 0)
      "zoom": false,                    // true = ضربة زوم 8% على السطر؛ أو رقم مثل 0.12
      "point": null,                    // tips: رقم النقطة التي تبدأ عند هذا السطر
      "broll": {"prompt": "slow dolly-in on a candlestick chart on a dark monitor", "file": null}
                                        // null = بلا لقطة · prompt بالإنجليزي · file يملؤه broll.py
    }
  ],
  "caption": "وصف البوست إذا طلبه"
}
```

## قواعد الأسطر

- سطر = ٢–٦ كلمات تظهر معاً. الطويل يُقسم (انسخ الكائن واقسم `words` بين الاثنين مع ضبط start/end من الكلمات).
- لا تعدّل `s`/`e` للكلمات إلا لإصلاح خطأ واضح (كلمة مدّتها 2 ثانية مثلاً).
- `em`: كلمة واحدة غالباً، اثنتان كحدّ أقصى. الاسم، الرقم، الفعل. ليس «في/من/على/أن».
- الأرقام بالأرقام اللاتينية (1,000) لأنّ خطّ الأرقام هو خطّه الإنجليزيّ.

## المشاهد `scenes`

كل مشهد: `{"kind": ..., "t0": بداية, "t1": نهاية, ...}`. الألوان: `"color": "accent"` (الافتراضيّ) أو `#hex`.
المواضع نِسَب من العرض/الارتفاع (0–1). **لا تضع مشهداً في منطقة الكابشن** (الكابشن «تحت الوجه» عند 0.69 من الارتفاع،
«الوسط» 0.51، «فوق» 0.32) ولا فوق الوجه (حول `zoomAnchor`).

| kind | متى | الحقول |
|---|---|---|
| `card` | فصل فكرة بشاشة داكنة | `lines: [{text, color?, size?}]`, `bg?`, `at?` (تباعد السطور بالثواني) |
| `stamp` | حكم أو تحذير: «خطأ!»، «مهمّ» | `text`, `x`, `y`, `rot?` (-8), `size?` (84), `textColor?` |
| `counter` | رقم يذكره: $5,000 · 87% | `value`, `prefix?`, `suffix?`, `label?`, `y?` (0.42), `size?`, `roll?` (1.2ث), `format?: "plain"` |
| `list` | نقاط تُعدّ | `items: [{text, at?}]` (at نسبة إلى t0), `y?` (0.3), `size?` |
| `bubble` | سؤال أو تعليق متابع | `name`, `text`, `y?` (0.6), `type?` (مدّة الكتابة) |
| `tag` | بطاقة تؤشّر عليه | `text`, `x`, `y` (0.55 أو أقلّ), `size?` |
| `dim` | سبوت لايت على جملة ثقيلة | `amount?` (0.6), `radius?` (34), `x?` (0.5) |
| `term` | مصطلح إنجليزيّ وترجمته | `text`, `sub?`, `y?` (0.18), `size?` |
| `bars` | مقارنة أرقام | `items: [{label, value, show?}]`, `y?`, `highlight?` (فهرس العمود الملوّن) |
| `versus` | شيء ضدّ شيء | `left`, `right`, `mid?` ("VS"), `y?`, `atRight?` |
| `flash` | ومضة بيضاء على ضربة | `amount?` (0.85)؛ t1-t0 ≈ 0.25 |

مثال واقعيّ (ريل ٢٢ ثانية): `stamp` عند 8.9–12.2 بـ«شمعة ↑» على يسار الشاشة فوق، `counter` 12.3–15.3 بـ$5,000،
`term` 15.5–19.3 بـTEXT ORBIT، `dim` على الجملة الأخيرة. مشهد واحد في الوقت الواحد.

## sentences.json (مدخل الخطّة)

`{"language": "ar", "sentences": [{"id", "start", "end", "text", "words": [{"w","s","e"}]}]}` — لا يُحرَّر؛ حرّر plan.json.
